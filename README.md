# 🧠 AI Text & PDF Summarizer (Flask + OpenAI)

A fullstack AI-powered web application that summarizes **text and PDF documents** into concise summaries using OpenAI GPT models.

---

## 🚀 Features

- ✂️ Summarize long text into short, meaningful summaries  
- 📄 Upload PDF files and extract summaries automatically  
- ⚡ Fast AI-powered responses using OpenAI GPT-4.1-mini  
- 🌐 Simple web interface using Flask templates  
- 🔄 REST API support for text and PDF summarization  
- 🔐 Secure API key handling using environment variables  

---

## 🛠️ Tech Stack

- **Backend:** Python, Flask, Flask-CORS  
- **AI Model:** OpenAI GPT-4.1-mini  
- **PDF Processing:** PyMuPDF (fitz)  
- **Frontend:** HTML, CSS, JavaScript (Flask templates)
